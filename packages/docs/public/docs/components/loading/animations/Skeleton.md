# QSkeleton

## 用途

`QSkeleton` 显示带渐变扫光效果的骨架屏占位区域；其宽度和高度随父容器撑满，最小高度为 `20px`。

## 基本用法

```vue
<script setup lang="ts">
import { QSkeleton } from 'qyani-components';
</script>

<template>
  <div style="height: 80px">
    <QSkeleton />
  </div>
</template>
```
