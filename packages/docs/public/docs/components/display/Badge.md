# QBadge

## 用途

在默认插槽内容的右上角展示数值/文本徽章或小圆点。

## 基本用法

```vue
<QBadge :value="12" :max="99">
  <button>消息</button>
</QBadge>
```

## Props

| 名称    | 类型                                                                  | 必填 | 默认值   | 说明                                                                              |
| ------- | --------------------------------------------------------------------- | ---- | -------- | --------------------------------------------------------------------------------- |
| `type`  | `'primary' \| 'success' \| 'warning' \| 'danger' \| 'gray' \| 'info'` | 否   | `'info'` | 徽章颜色类型。                                                                    |
| `value` | `number \| string`                                                    | 否   | `1`      | 徽章显示值；数值或可被 `parseInt` 解析的字符串超过 `max` 时，显示固定文本 `99+`。 |
| `max`   | `number`                                                              | 否   | `99`     | 触发超限显示的阈值。                                                              |
| `dot`   | `boolean`                                                             | 否   | `false`  | 是否仅显示小圆点；为 `true` 时不显示 `value`。                                    |

## Emits

无。

## Slots

| 名称     | 作用域参数 | 说明                                   |
| -------- | ---------- | -------------------------------------- |
| 默认插槽 | 无         | 徽章所附着的内容；未提供时仅渲染徽章。 |

## Exposes

无。
