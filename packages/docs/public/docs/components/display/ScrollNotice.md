# QScrollNotice

## 用途

以从右向左的动画滚动展示通知内容。

## 基本用法

```vue
<QScrollNotice :speed="2">系统将在今晚维护</QScrollNotice>
```

## Props

| 名称    | 类型     | 必填 | 默认值 | 说明                      |
| ------- | -------- | ---- | ------ | ------------------------- |
| `speed` | `number` | 否   | `1`    | 滚动速度，单位为像素/帧。 |

## Emits

无。

## Slots

| 名称     | 作用域参数 | 说明                                     |
| -------- | ---------- | ---------------------------------------- |
| 默认插槽 | 无         | 要滚动展示的通知内容；未提供时内容为空。 |

## Exposes

无。
