# QCarouselItem

## 用途

轮播项容器，通常作为 `QCarousel` 的默认插槽子项使用。

## 基本用法

```vue
<QCarousel :width="320" :height="180">
  <QCarouselItem>第一项</QCarouselItem>
</QCarousel>
```

## Props

无。

## Emits

无。

## Slots

| 名称     | 作用域参数 | 说明                             |
| -------- | ---------- | -------------------------------- |
| 默认插槽 | 无         | 轮播项内容；未提供时轮播项为空。 |

## Exposes

无。
