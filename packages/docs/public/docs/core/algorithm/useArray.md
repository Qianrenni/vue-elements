# useArray

## 用途

提供在已按比较规则排序的数组中定位目标值左右边界的二分查找函数。函数不会修改输入数组。

## API

### `binarySearchLeft<T>`

从左向右查找 `target` 的首次出现位置。

| 参数     | 类型                     | 必填 | 含义                                                         |
| -------- | ------------------------ | ---- | ------------------------------------------------------------ |
| `array`  | `T[]`                    | 是   | 已按 `func` 的规则排序的数组。                               |
| `target` | `T`                      | 是   | 要查找的目标值。                                             |
| `func`   | `(a: T, b: T) => number` | 是   | 比较函数；负数表示 `a < b`，`0` 表示相等，正数表示 `a > b`。 |

- 返回：`number`，目标首次出现的索引；不存在时为 `-1`。
- Throws：无。

### `binarySearchRight<T>`

从右向左查找 `target` 的最后一次出现位置。

| 参数     | 类型                     | 必填 | 含义                                                         |
| -------- | ------------------------ | ---- | ------------------------------------------------------------ |
| `array`  | `T[]`                    | 是   | 已按 `func` 的规则排序的数组。                               |
| `target` | `T`                      | 是   | 要查找的目标值。                                             |
| `func`   | `(a: T, b: T) => number` | 是   | 比较函数；负数表示 `a < b`，`0` 表示相等，正数表示 `a > b`。 |

- 返回：`number`，目标最后一次出现的索引；不存在时为 `-1`。
- Throws：无。
