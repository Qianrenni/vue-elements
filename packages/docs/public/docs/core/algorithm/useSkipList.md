# useSkipList

## 用途

`UseSkipList` 是按比较规则有序且不允许重复元素的跳表，支持插入、删除、按排名访问和范围读取。

## `UseSkipList<T>`

### 职责

通过概率分层链表维护有序元素集合，提供查找、插入、删除及排名相关操作。默认比较器只支持 `number` 和 `string`；其他类型应提供 `compare`。

### 构造函数

| 参数        | 类型                     | 必填 | 默认值                 | 含义                                                       |
| ----------- | ------------------------ | ---- | ---------------------- | ---------------------------------------------------------- |
| `P`         | `number`                 | 否   | `0.25`                 | 节点晋升到下一层的概率因子。                               |
| `MAX_LEVEL` | `number`                 | 否   | `32`                   | 允许的最大层数。                                           |
| `compare`   | `(a: T, b: T) => number` | 否   | number/string 自然顺序 | 比较器；负数表示 `a < b`，`0` 表示相等，正数表示 `a > b`。 |

- Throws：默认比较器参与比较时，若元素不是同为 `number` 或同为 `string`，会抛出 `Error`。

### 公开属性

| 属性     | 类型             | 含义               |
| -------- | ---------------- | ------------------ |
| `length` | `number`（只读） | 跳表当前元素数量。 |

### 公开方法

| 方法            | 参数                             | 返回             | 说明                                                                                               | Throws                                     |
| --------------- | -------------------------------- | ---------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `insert`        | `member: T`                      | `boolean`        | 插入元素；已存在时返回 `false`，成功插入返回 `true`。                                              | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `delete`        | `member: T`                      | `boolean`        | 删除元素；不存在时返回 `false`。                                                                   | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `get_by_rank`   | `rank: number`                   | `T \| null`      | 获取从 `0` 开始的排名对应元素；排名无效时为 `null`。                                               | 无。                                       |
| `get_rank`      | `member: T`                      | `number \| null` | 获取元素从 `0` 开始的排名；不存在时为 `null`。                                                     | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `get_first`     | 无                               | `T \| null`      | 获取最小元素；空表时为 `null`。                                                                    | 无。                                       |
| `get_last`      | 无                               | `T \| null`      | 获取最大元素；空表时为 `null`。                                                                    | 无。                                       |
| `range`         | `start: number`，`count: number` | `T[]`            | 从正向 `start`（0-based）开始最多读取 `count` 个元素；负 `start` 按 `0` 处理，无效范围返回空数组。 | 无。                                       |
| `reverse_range` | `start: number`，`count: number` | `T[]`            | 从末尾向前计数的 `start`（0-based）开始，最多逆序读取 `count` 个元素；无效范围返回空数组。         | 无。                                       |
