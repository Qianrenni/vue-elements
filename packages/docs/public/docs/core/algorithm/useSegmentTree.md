# useSegmentTree

## 用途

`UseSegmentTree` 是支持区间更新和区间查询的泛型线段树。通过合并函数和懒标记应用函数，可用于区间和、最大/最小值、区间覆盖或区间增量等场景；区间端点均为闭区间、从 `0` 开始。

## `UseSegmentTree<T = number, Lazy = number>`

### 职责

维护输入数组的线段树和懒标记，执行区间更新并返回区间合并结果。实例创建时会复制数据值到内部树结构，之后操作不修改传入的 `data` 数组。

### 构造函数

| 参数         | 类型                                                               | 必填 | 默认值   | 含义                                                                                      |
| ------------ | ------------------------------------------------------------------ | ---- | -------- | ----------------------------------------------------------------------------------------- |
| `data`       | `T[]`                                                              | 是   | —        | 初始化线段树的原始数据。                                                                  |
| `rootFunc`   | `(left: number, right: number, lazyValue: Lazy, oldValue: T) => T` | 是   | —        | 将懒标记应用到节点值的函数；`left`、`right` 是该节点管理的闭区间，`oldValue` 是旧聚合值。 |
| `mergeFunc`  | `(a: T, b: T) => T`                                                | 否   | 数值加法 | 合并左右子区间结果的函数。                                                                |
| `defaultVal` | `T`                                                                | 否   | `0 as T` | 无交集查询时返回的单位元，也用于补齐叶节点。                                              |

- Throws：无。

### 公开属性

无。

### 公开方法

#### `update`

更新闭区间内的值，具体更新语义由 `rootFunc` 决定。

| 参数    | 类型     | 必填 | 含义                          |
| ------- | -------- | ---- | ----------------------------- |
| `left`  | `number` | 是   | 更新区间的左端点（0-based）。 |
| `right` | `number` | 是   | 更新区间的右端点（0-based）。 |
| `value` | `Lazy`   | 是   | 传给 `rootFunc` 的懒标记值。  |

- 返回：`void`。
- Throws：无。

#### `query`

查询闭区间的聚合结果。

| 参数    | 类型     | 必填 | 含义                          |
| ------- | -------- | ---- | ----------------------------- |
| `left`  | `number` | 是   | 查询区间的左端点（0-based）。 |
| `right` | `number` | 是   | 查询区间的右端点（0-based）。 |

- 返回：`T`，通过 `mergeFunc` 合并得到的区间结果；无交集部分使用 `defaultVal`。
- Throws：无。
