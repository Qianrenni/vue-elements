# QMessage

## 用途

展示成功、警告、错误或信息类文本消息，并按消息类型应用对应颜色样式。

## 基本用法

```vue
<QMessage message="保存成功" type="success" />
```

## Props

| 名称      | 类型                                          | 必填 | 默认值 | 说明                     |
| --------- | --------------------------------------------- | ---- | ------ | ------------------------ |
| `message` | `string`                                      | 是   | 无     | 要展示的消息文本。       |
| `type`    | `'success' \| 'warning' \| 'error' \| 'info'` | 是   | 无     | 消息类型，决定文本颜色。 |

## Emits

无。

## Slots

无。

## Exposes

无。
