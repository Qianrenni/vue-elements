# QIcon

## 用途

加载并渲染指定名称的 SVG 图标；当 `icon` 或 `size` 变化时会重新加载图标内容。

## 基本用法

```vue
<QIcon icon="Left" :size="18" />
```

## Props

| 名称   | 类型               | 必填 | 默认值 | 说明                   |
| ------ | ------------------ | ---- | ------ | ---------------------- |
| `icon` | `string`           | 是   | 无     | 要加载的图标名称。     |
| `size` | `number \| string` | 否   | `24`   | 图标宽高使用的尺寸值。 |

## Emits

无。

## Slots

无。

## Exposes

无。
