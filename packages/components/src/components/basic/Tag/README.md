# QTag

## 用途

展示单行文本标签，可设置文字颜色和背景色。

## 基本用法

```vue
<QTag text="推荐" color="#fff" background="#409eff" />
```

## Props

| 名称         | 类型     | 必填 | 默认值                       | 说明           |
| ------------ | -------- | ---- | ---------------------------- | -------------- |
| `text`       | `string` | 是   | 无                           | 标签文本。     |
| `color`      | `string` | 否   | `'white'`                    | 标签文字颜色。 |
| `background` | `string` | 否   | `'var(--tag-primary-color)'` | 标签背景色。   |

## Emits

无。

## Slots

无。

## Exposes

无。
