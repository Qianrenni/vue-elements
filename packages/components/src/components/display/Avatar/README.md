# QAvatar

## 用途

展示圆形头像。组件进入视口后才渲染图片；加载期间显示骨架屏，加载失败时显示错误占位。

## 基本用法

```vue
<QAvatar url="/avatar.png" size="48px" alt="用户头像" />
```

## Props

| 名称   | 类型     | 必填 | 默认值   | 说明                   |
| ------ | -------- | ---- | -------- | ---------------------- |
| `url`  | `string` | 是   | 无       | 头像图片地址。         |
| `size` | `string` | 否   | `'2rem'` | 头像容器的宽度和高度。 |
| `alt`  | `string` | 否   | `'人像'` | 图片替代文本。         |

## Emits

无。

## Slots

无。

## Exposes

无。
