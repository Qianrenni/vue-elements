# QSwiperAction

## 用途

为主内容提供向左滑动后显示右侧操作区的交互，同时支持触摸和鼠标拖动。

## 基本用法

```vue
<QSwiperAction :threshold="50" @swipe="handleSwipe">
  列表项内容
  <template #action>
    <QFormButton>删除</QFormButton>
  </template>
</QSwiperAction>
```

## Props

| 名称        | 类型      | 必填 | 默认值  | 说明                                                  |
| ----------- | --------- | ---- | ------- | ----------------------------------------------------- |
| `disabled`  | `boolean` | 否   | `false` | 是否禁用滑动和拖动。                                  |
| `threshold` | `number`  | 否   | `50`    | 结束拖动时判定为展开操作区的左滑距离阈值，单位为 px。 |

## Emits

| 事件          | 载荷类型  | 触发时机                                                                                       |
| ------------- | --------- | ---------------------------------------------------------------------------------------------- |
| `swipe`       | 无        | 松开时左滑距离达到 `threshold` 且右侧操作区宽度大于 0，操作区展开后触发。                      |
| `update:open` | `boolean` | 松开拖动后触发；达到阈值时发送 `true`，否则回弹关闭并发送 `false`。操作区宽度为 0 时不会触发。 |

## Slots

| 名称      | 作用域参数 | 后备内容             |
| --------- | ---------- | -------------------- |
| `default` | 无         | 无；主内容区域。     |
| `action`  | 无         | 无；右侧滑出操作区。 |

## Exposes

无。
