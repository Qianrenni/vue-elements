# useHeap

## 用途

`UseHeap` 是可作为优先队列使用的泛型堆。比较器返回 `true` 表示第一个元素优先级更高；默认比较器为 `a < b`，因此默认是最小堆，且仅适用于可比较的 `number`/`string`。

## `UseHeap<T>`

### 职责

维护堆结构，支持插入、查看和弹出最高优先级元素；也提供直接操作数组的静态堆化、入堆、出堆和堆排序方法。

### 构造函数

| 参数      | 类型                      | 必填 | 默认值            | 含义                                                 |
| --------- | ------------------------- | ---- | ----------------- | ---------------------------------------------------- |
| `compare` | `(a: T, b: T) => boolean` | 否   | `(a, b) => a < b` | 优先级比较器；返回 `true` 表示 `a` 应位于 `b` 之前。 |

- Throws：无（默认比较器遇到不可使用 `<` 比较的值时，运行时行为由 JavaScript 决定）。

### 公开属性

| 属性   | 类型             | 含义             |
| ------ | ---------------- | ---------------- |
| `size` | `number`（只读） | 当前堆元素数量。 |

### 静态方法

| 方法          | 参数                                                              | 返回             | 说明                                                   | Throws |
| ------------- | ----------------------------------------------------------------- | ---------------- | ------------------------------------------------------ | ------ |
| `heaplify<T>` | `arr: T[]`，`compare: (a: T, b: T) => boolean`                    | `void`           | 原地将数组构造成堆。                                   | 无。   |
| `heapPop<T>`  | `arr: T[]`，`compare: (a: T, b: T) => boolean`                    | `T \| undefined` | 原地弹出数组堆顶；空数组返回 `undefined`。             | 无。   |
| `heapPush<T>` | `arr: T[]`，`item: T`，`compare: (a: T, b: T) => boolean`         | `void`           | 原地向数组堆插入元素。                                 | 无。   |
| `heapSort<T>` | `arr: T[]`，`compare?: (a: T, b: T) => boolean = (a, b) => a < b` | `void`           | 原地排序；最小堆比较器得到升序，最大堆比较器得到降序。 | 无。   |

### 实例方法

| 方法      | 参数      | 返回             | 说明                                                       | Throws |
| --------- | --------- | ---------------- | ---------------------------------------------------------- | ------ |
| `add`     | `item: T` | `void`           | 插入元素并维持堆性质。                                     | 无。   |
| `pop`     | 无        | `T \| undefined` | 移除并返回最高优先级元素；空堆为 `undefined`。             | 无。   |
| `sort`    | 无        | `void`           | 原地排序内部数组；排序后堆结构被破坏，不应继续作为堆使用。 | 无。   |
| `clear`   | 无        | `void`           | 清空堆。                                                   | 无。   |
| `peek`    | 无        | `T \| undefined` | 查看最高优先级元素但不移除；空堆为 `undefined`。           | 无。   |
| `isEmpty` | 无        | `boolean`        | 判断堆是否为空。                                           | 无。   |
| `toArray` | 无        | `T[]`            | 返回内部数组的浅拷贝，不改变堆。                           | 无。   |
