# QLazyImage

## 用途

展示懒加载图片。容器进入视口后才渲染图片；加载期间显示骨架屏，加载失败时显示“加载失败”占位。

## 基本用法

```vue
<QLazyImage src="/banner.png" width="320px" height="180px" alt="横幅" />
```

## Props

| 名称     | 类型               | 必填 | 默认值   | 说明                           |
| -------- | ------------------ | ---- | -------- | ------------------------------ |
| `src`    | `string`           | 是   | 无       | 图片地址。                     |
| `alt`    | `string`           | 否   | `''`     | 图片替代文本。                 |
| `width`  | `string \| number` | 否   | `'100%'` | 容器宽度；数值会转为像素单位。 |
| `height` | `string \| number` | 否   | `'100%'` | 容器高度；数值会转为像素单位。 |
