# useAVLTree

## 用途

提供支持重复值和自定义排序规则的 AVL 自平衡二叉搜索树。重复值由单个节点的计数器保存，插入、删除和查找均通过比较器确定顺序。

## `AVLNode<T>`

### 职责

表示 `UseAVLTree` 中的一个节点，并保存节点值、左右子节点、子树高度及重复次数。

### 构造函数

| 参数    | 类型 | 必填 | 含义           |
| ------- | ---- | ---- | -------------- |
| `value` | `T`  | 是   | 节点存储的值。 |

- Throws：无。

### 公开属性

| 属性     | 类型                 | 含义                           |
| -------- | -------------------- | ------------------------------ |
| `value`  | `T`                  | 节点值。                       |
| `left`   | `AVLNode<T> \| null` | 左子节点，初始为 `null`。      |
| `right`  | `AVLNode<T> \| null` | 右子节点，初始为 `null`。      |
| `height` | `number`             | 子树高度，叶节点初始为 `1`。   |
| `count`  | `number`             | 相同值的出现次数，初始为 `1`。 |

### 公开方法

无。

## `UseAVLTree<T>`

### 职责

维护 AVL 平衡和节点池，提供有序集合操作；`size` 统计全部元素（包含重复值）。默认比较器仅支持 `number` 或 `string`。

### 构造函数

| 参数        | 类型                     | 必填 | 默认值                 | 含义                                                       |
| ----------- | ------------------------ | ---- | ---------------------- | ---------------------------------------------------------- |
| `compare`   | `(a: T, b: T) => number` | 否   | number/string 自然顺序 | 比较器；负数表示 `a < b`，`0` 表示相等，正数表示 `a > b`。 |
| `POOL_SIZE` | `number`                 | 否   | `16`                   | 最多复用的已删除节点数。                                   |

- Throws：默认比较器参与比较时，若元素不是同为 `number` 或同为 `string`，会抛出 `Error`。

### 公开属性

| 属性   | 类型             | 含义                       |
| ------ | ---------------- | -------------------------- |
| `size` | `number`（只读） | 树中元素总数，包含重复值。 |

### 公开方法

| 方法        | 参数                            | 返回                    | 说明                                              | Throws                                     |
| ----------- | ------------------------------- | ----------------------- | ------------------------------------------------- | ------------------------------------------ |
| `insert`    | `value: T`                      | `void`                  | 插入值；重复值会增加节点的 `count`。              | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `delete`    | `value: T`                      | `boolean`               | 删除一个匹配值；成功为 `true`，不存在为 `false`。 | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `find`      | `value: T`                      | `AVLNode<T> \| null`    | 查找值并返回节点；不存在为 `null`。               | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `has`       | `value: T`                      | `boolean`               | 判断值是否存在。                                  | 默认比较器不支持的元素类型会抛出 `Error`。 |
| `min`       | 无                              | `T \| undefined`        | 返回最小值；空树为 `undefined`。                  | 无。                                       |
| `max`       | 无                              | `T \| undefined`        | 返回最大值；空树为 `undefined`。                  | 无。                                       |
| `inOrder`   | `ascending?: boolean = true`    | `Generator<AVLNode<T>>` | 中序遍历；`true` 为升序，`false` 为降序。         | 无。                                       |
| `preOrder`  | `leftPriority?: boolean = true` | `Generator<AVLNode<T>>` | 前序遍历；指定访问左右子树的优先级。              | 无。                                       |
| `postOrder` | `leftPriority?: boolean = true` | `Generator<AVLNode<T>>` | 后序遍历；指定访问左右子树的优先级。              | 无。                                       |
| `toArray`   | `unique?: boolean = false`      | `T[]`                   | 返回升序数组；`true` 时每个不同值只保留一次。     | 无。                                       |
| `clear`     | 无                              | `void`                  | 清空树中的元素。                                  | 无。                                       |
| `isEmpty`   | 无                              | `boolean`               | 判断树是否为空。                                  | 无。                                       |
