# useGraph

## 用途

提供以数字节点和邻接表表示的图的广度优先搜索（BFS）与深度优先搜索（DFS）。节点编号应可直接作为 `edges`、结果数组的索引使用。

## API

### `BFS`

按队列顺序遍历图；未指定起点时，依次遍历所有未访问节点。

| 参数         | 类型                               | 必填 | 默认值    | 含义                                               |
| ------------ | ---------------------------------- | ---- | --------- | -------------------------------------------------- |
| `nodes`      | `Set<number>`                      | 是   | —         | 图中的节点集合。                                   |
| `edges`      | `number[][]`                       | 是   | —         | 邻接表，`edges[u]` 是从节点 `u` 可到达的节点列表。 |
| `start`      | `number`                           | 否   | `-1`      | 起始节点；`-1` 表示遍历所有连通分量。              |
| `weightFunc` | `(u: number, v: number) => number` | 否   | `() => 1` | 访问边 `u -> v` 时累加到距离的边权函数。           |

- 返回：`{ dist: number[]; prev: number[] }`。`dist` 为首次访问时计算的累计距离，未访问节点为 `Infinity`；`prev` 为首次访问该节点的前驱，起点或未访问节点为 `-1`。
- Throws：无。

### `DFS`

按栈顺序遍历图；未指定起点时，依次遍历所有未访问节点。

| 参数         | 类型                               | 必填 | 默认值    | 含义                                               |
| ------------ | ---------------------------------- | ---- | --------- | -------------------------------------------------- |
| `nodes`      | `Set<number>`                      | 是   | —         | 图中的节点集合。                                   |
| `edges`      | `number[][]`                       | 是   | —         | 邻接表，`edges[u]` 是从节点 `u` 可到达的节点列表。 |
| `start`      | `number`                           | 否   | `-1`      | 起始节点；`-1` 表示遍历所有连通分量。              |
| `weightFunc` | `(u: number, v: number) => number` | 否   | `() => 1` | 访问边 `u -> v` 时累加到距离的边权函数。           |

- 返回：`{ dist: number[]; prev: number[] }`。`dist` 为首次访问时计算的累计距离，未访问节点为 `Infinity`；`prev` 为首次访问该节点的前驱，起点或未访问节点为 `-1`。
- Throws：无。
