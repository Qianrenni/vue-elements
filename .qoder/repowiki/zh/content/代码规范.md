# 代码规范

## Prettier 格式化

项目使用 Prettier 3 + `@trivago/prettier-plugin-sort-imports` 插件统一代码风格：

| 配置项       | 值       |
| ------------ | -------- |
| printWidth   | 80       |
| tabWidth     | 2        |
| 缩进         | 空格     |
| 分号         | 始终添加 |
| 引号         | 单引号   |
| 尾逗号       | 所有位置 |
| 行尾         | CRLF     |
| 箭头函数括号 | 始终包裹 |

**来源**: [.prettierrc.cjs](file://.prettierrc.cjs)

### Import 排序规则

导入语句按以下分组排序（组间空行分隔）：

1. **第三方依赖**（`<THIRD_PARTY_MODULES>`）
2. **内部 workspace 包**（`^@qianrenni/`）
3. **相对路径导入**（`^[.]`）

每组内按字母顺序排序，命名空间导入（`import * as`）置于组顶，大小写不敏感。

## ESLint 配置

使用 ESLint 10 Flat 配置，由 `@qianrenni/eslint-config` 包提供统一规则：

- 支持文件类型：JS/TS/Vue/JSON/JSONC/JSON5/CSS
- 忽略 `node_modules/`、`dist/`、`.vscode/`、lock 文件
- Vue 文件使用 `vue-eslint-parser` 搭配 TypeScript parser
- 继承 `eslint:recommended`、`typescript-eslint/recommended`、`plugin:vue/essential`

**来源**: [packages/eslint/eslint.config.mjs](file://packages/eslint/eslint.config.mjs)

## Git Hooks

使用 Husky 9 + lint-staged 实现 pre-commit 自动检查：

- 触发时机：git commit 前
- 检查范围：变化的 `*.{js,ts,vue,css,md}` 文件
- 执行流程：先 `prettier --write` 格式化，再 `eslint --cache --fix` 修复

**来源**: [.husky/pre-commit](file://.husky/pre-commit) · [package.json](file://package.json)（lint-staged 配置）

## IDE 配置

VS Code 工作区配置提供：

- 推荐的扩展：Vue Language Features、ESLint、Prettier
- 保存时自动格式化
- `editor.codeActionsOnSave` 配置 ESLint 自动修复

**来源**: [.vscode/settings.json](file://.vscode/settings.json) · [.vscode/extensions.json](file://.vscode/extensions.json)
