# 项目概述

qyani-components 是一个 Vue 3 + TypeScript 前端组件库 monorepo，由 pnpm workspace 管理。提供 50+ UI 组件、配套文档站点及共享 ESLint 配置。

**引用文件**: [package.json](file://package.json) · [pnpm-workspace.yaml](file://pnpm-workspace.yaml)

## Monorepo 结构

项目包含 3 个子包，均位于 `packages/` 目录下：

| 包路径                 | 包名                     | 用途                          |
| ---------------------- | ------------------------ | ----------------------------- |
| `packages/components/` | `qyani-components`       | 核心组件库（Vite 库模式构建） |
| `packages/docs/`       | `@qyani-components/docs` | 文档站点（Vite 应用模式）     |
| `packages/eslint/`     | `@qyani/eslint-config`   | 共享 ESLint Flat 配置         |

**来源**: [packages/components/package.json](file://packages/components/package.json) · [packages/docs/package.json](file://packages/docs/package.json) · [packages/eslint/package.json](file://packages/eslint/package.json)

## 技术栈

| 类别      | 技术                                       |
| --------- | ------------------------------------------ |
| 框架      | Vue 3 (Composition API + `<script setup>`) |
| 语言      | TypeScript (strict mode)                   |
| 构建      | Vite 7 (lib mode + app mode)               |
| 类型检查  | vue-tsc 3                                  |
| 测试      | Vitest 3                                   |
| 包管理    | pnpm 10 workspace                          |
| 代码风格  | ESLint 10 (Flat config) + Prettier 3       |
| Git Hooks | Husky + lint-staged                        |

**来源**: [package.json](file://package.json) · [packages/components/vite.config.ts](file://packages/components/vite.config.ts)

## 组件分类

组件按功能组织在 `src/components/{category}/` 目录下：

- **basic/** — Icon, Message, Pagination, Tag
- **display/** — Avatar, Badge, Carousel, CarouselItem, Divider, LazyImage, MarkdownRender, ProgressBar, ScrollNotice
- **form/** — FormButton, FormCheckboxGroup, FormColorPicker, FormDatePicker, FormFileUpload, FormRadioGroup, FormRangeSlider, FormSelect, FormSwitch, FormTable, FormText, FormTextarea, Search
- **layout/** — Card, Collapse, CollapseItem, CollapsibleSection, Dialog, Drawer, PopContainer, ScrollContainer, SwiperAction, Tree, TreeNode
- **loading/** — Loading, Breathing, Skeleton, Spinner
- **navigation/** — NavSection, Tab
- **theme/** — ThemeToggle

所有组件均以 `Q` 前缀命名（如 QIcon、QAvatar）。

## 工具函数

位于 `packages/components/src/utils/`：

- **algorithm/** — useAVLTree, useArray, useGraph, useHeap, useRedBlackTree, useSegmentTree, useSkipList, useSort
- **business/** — useClip, useDebounce, useFollowSystemTheme, useLocalStorage, useLRUCache, useMemoryCache, useMessage, useNullHandel, useObject, useScreenSize, useShowLoading, useThrottle, useTimeDisplay, useTimeUtils, useWindowResize

事件工具位于 `packages/components/src/events/`：useDrag, useFormEvents, useMousePosition

## 快速开始

```bash
pnpm install            # 安装所有 workspace 依赖
pnpm run dev            # 启动文档开发服务器
pnpm run components:build  # 构建组件库
pnpm run docs:build     # 构建文档站点
```
