# 部署指南

文档站点通过 GitHub Actions 自动构建并部署到 GitHub Pages。

**仓库**: `Qianrenni/vue-elements`
**线上地址**: `https://qianrenni.github.io/vue-elements/`

## 构建产物

组件库构建产物位于 `packages/components/dist/`，文档站点构建产物位于 `packages/docs/dist/`。

```bash
# 完整构建（组件库 + 文档站点）
pnpm run docs:build
```

## 自动化部署（推荐）

项目已配置 GitHub Actions 工作流 [.github/workflows/deploy.yml](file://.github/workflows/deploy.yml)，自动完成以下步骤：

1. Checkout 代码
2. 安装 pnpm + Node.js 22
3. 安装依赖（`pnpm install --frozen-lockfile`）
4. 构建组件库（`pnpm run components:build`）
5. 构建文档站点（`pnpm run docs:build`）
6. 部署到 `gh-pages` 分支

GitHub Pages 从 `gh-pages` 分支根目录提供内容。

### 触发方式

- **自动触发**：推送到 `main` 或 `master` 分支
- **手动触发**：在 GitHub Actions 页面点击 "Run workflow"

### 一次性配置

首次部署前，需要在 GitHub 仓库设置中配置 Pages：

1. 打开仓库 **Settings → Pages**
2. **Build and deployment** 选择 **Deploy from a branch**
3. 分支选择 `gh-pages`，目录选 `/ (root)`
4. 保存即可

## 手动部署（替代方案）

如果不想使用 GitHub Actions，也可以本地构建后手动部署：

```bash
# 安装 gh-pages 工具（如果尚未安装）
pnpm add -D -w gh-pages

# 构建
pnpm run components:build
pnpm run docs:build

# 部署
npx gh-pages -d packages/docs/dist -b gh-pages
```

## 生产构建的 Base 路径

文档站点的生产构建使用 `base: '/vue-elements/'`，与 GitHub Pages 的子路径部署匹配。如需修改仓库名或部署到自定义域名，需同步更新 [packages/docs/vite.config.ts](file://packages/docs/vite.config.ts) 中的 `base` 配置。
