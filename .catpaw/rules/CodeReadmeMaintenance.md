# 代码 README 维护规则

创建或修改 Vue 组件、类文件、公共函数或外部可调用函数时，必须同步维护模块目录中最近的 `README.md`：存在则更新，不存在则在该模块目录创建。README 内容必须与最终实现保持一致，仅记录对使用者有影响的公共 API，不暴露私有实现细节。

## Vue 组件

组件 README 必须包含用途与基本用法，并说明以下 API：

- **Props**：名称、TypeScript 类型、必填/可选、默认值及行为。
- **Emits**：事件名、载荷类型及触发时机。
- **Slots**：插槽名、作用域参数及默认/回退行为。
- **Exposes**：通过 `defineExpose` 暴露的 API，以及参数、返回值和调用说明。

Props、Emits、Slots 或 Exposes 不存在时，必须明确标注“无”。

## 函数

每个公共或外部可调用函数必须在 README 中说明：

- 功能与使用场景。
- 参数：名称、TypeScript 类型、是否可选及含义。
- 返回值：TypeScript 类型及含义。
- 异常：异常类型及触发条件；无主动抛出异常时标注“无”。

函数的 JSDoc 必须与 README 保持同步。

## 类文件

类 README 必须说明：

- 类的职责、生命周期和预期使用方式。
- 构造函数参数与初始化行为。
- 相关公开属性或可观察状态。
- 每个公开方法的功能、参数、返回值和抛出异常。

## 文档格式

仅保留模块适用的章节。Props、事件、插槽、方法或函数较多时使用表格；描述使用简洁中文，除非当前模块的既有文档使用其他语言。

```markdown
# <模块名称>

## 用途

## 使用方式

## Props

## Emits

## Slots

## Exposes

## API

### `<函数或方法名称>`

- 参数：
- 返回值：
- 异常：
```

完成代码变更前，确认每一个变更的公共组件 API、类 API 和函数签名均准确反映在最近的 README 中。
